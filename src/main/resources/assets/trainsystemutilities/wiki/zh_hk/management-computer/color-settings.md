# 顏色設置

```embed:color-settings
```

管理用計算機的顏色設置彈窗。自定義顯示器上每個元素的顏色。

[[TOC]]

## 如何打開

1. **放置**管理用計算機方塊並**右鍵點擊**它以打開界面。
2. **點擊界面底部的"🎨 顏色"按鈕**打開顯示器顏色設置彈窗。

## 可重新着色的元素（目標）

**點擊彈窗頂部的"目標："下拉菜單**，然後**點擊**你想重新着色的元素。可用元素：

| 目標 | 描述 |
|---|---|
| 標題 | 面板標題文字顏色 |
| 邊框 | 面板邊框顏色 |
| 列車名 | 列車名文字顏色 |
| 速度 / 狀態 | 速度和運行狀態文字顏色 |
| 目的地 | 目的地文字顏色 |
| 時鐘 | 時鐘顯示顏色 |
| 統計數值 | 車站數和列車數等數字的顏色 |
| 信號（綠） | 地圖上綠色信號的顏色 |
| 信號（紅） | 地圖上紅色信號的顏色 |
| 地圖線條 | 地圖上線條的顏色 |
| 地圖車站 | 地圖上車站圖標的顏色 |
| 地圖列車 | 地圖上列車圖標的顏色 |

## 用法

1. **選擇目標**：點擊"目標："下拉菜單 → 從上方列表中點擊一個元素。
2. **選擇顏色**：直接**點擊下方某個預設顏色**即可應用到所選目標。"當前："顯示當前顏色。
3. **還原**：**點擊"重置"按鈕**可將所選目標恢復為默認顏色。**點擊"全部重置"按鈕**可將所有目標恢復為默認顏色。
4. **關閉**：**點擊彈窗右上角的 ✕（關閉）按鈕**。

## 預設

12 種預設顏色可通過**點擊**一鍵應用。

## 範圍

顏色設置以管理用計算機為單位。
相同的顏色會應用到每個已連接的顯示器。
