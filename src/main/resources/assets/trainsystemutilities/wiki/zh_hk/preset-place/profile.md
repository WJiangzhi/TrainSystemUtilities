# 個人資料

![](bws:trainsystemutilities:wiki/screens/preset-place-profile__ja_jp.png)

按用户區分的頁面。有兩種模式：自己的主頁和他人的主頁。

[[TOC]]

## 打開 {#open}

- **你自己的主頁** … 在 **GUI 模式**下**右鍵**[列車預設工具](../train-preset-tool/browse.md) → 將模式設為 **`Place`（公開）**，並**左鍵**頂部的你的名字 / 圖標區域。
- **他人的主頁** … 在[預設詳情](detail.md)頁面，**左鍵上傳者的名字**即可打開。

首次打開時，可能會要求你進行 Microsoft 賬號認證。請按界面提示操作。

## 模式 {#modes}

視頁面是自己還是他人，可執行的操作有所不同。

| 模式 | 內容 |
|---|---|
| **自己的** | 編輯主頁 / 更換圖標 / 查看數據 / 前往創作者中心 |
| **他人的** | 瀏覽公開預設 / 關注 |

## 按鈕操作 {#buttons}

| 按鈕 | 顯示條件 | 操作 / 行為 |
|---|---|---|
| 關注 | 他人主頁 | **左鍵**關注 / 取消關注（已關注時為灰色，未關注時為橙色） |
| 創作者中心 | 自己的主頁 | **左鍵**打開[創作者中心](creator-center.md) |
| 編輯圖標 | 僅自己的主頁和官方賬號 | **左鍵**打開圖標編輯器 |
| 預設卡片 | 兩者 | **左鍵**前往該預設的[詳情](detail.md) |
| × / 返回 | 兩者 | 關閉 / 返回 |

## 主頁圖標 {#icon}

支持 SVG 格式的自定義圖標。
編輯在主頁圖標編輯器中完成（一個專用彈窗，從你自己主頁上的 **"編輯圖標"按鈕**打開）：

- 加載 SVG 文件
- 調整縮放 / 偏移
- 設置背景色 / 邊框色
- **僅官方賬號可編輯**（普通用户不會顯示編輯按鈕）

## 數據顯示

你自己的主頁會顯示：
- 公開預設數
- 累計下載量
- 累計點贊數
- 關注者數
