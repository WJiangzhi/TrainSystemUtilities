# 模拟逆变器

```embed:item id=trainsystemutilities:fe_inverter_dummy size=48 label=true
```

一种"仅外观"的 FE 逆变器变体，适合希望将**受电弓纯粹作为装饰**、不启用 FE 取流 / 驱动系统的玩家。

[[TOC]]

## 概述

在视觉和放置行为上，它是与真正的[FE 逆变器](fe-inverter.md)完全相同的 3 方块多方块结构，但它**没有内部 FE 缓冲**——即便安装在列车上，它也不会执行任何电气处理。

## 能做 / 不能做的事

| 功能 | 真 FE 逆变器 | 模拟逆变器 |
|---|---|---|
| 外观（模型 / 纹理） | ✅ | ✅（相同） |
| 3 方块多方块放置 | ✅ | ✅（相同） |
| 管理 UI 中的电气化信息面板 | ✅ | ✅ |
| 从 UI 展开 / 折叠受电弓 | ✅ | ✅ |
| 接触网接触检测（受电弓杆下压视觉） | ✅ | ✅ |
| FE 取流（从接触网接收电力） | ✅ | ❌ |
| FE 保活成本消耗 | ✅ | ❌ |
| 全部受电弓折叠时强制停车 | ✅ | ❌ |
| 为相邻 FE 机器供电 | ✅ | ❌ |

## 使用场景

### 1. 装饰性列车受电弓

`[车厢车顶：受电弓 + 模拟逆变器]`

当你想让列车*看起来*已电气化，但又希望游戏玩法仍基于 Create 的动能驱动时使用。
由于仍可从管理 UI 展开 / 折叠受电弓，你可以实现诸如只在停靠车站时降下受电弓等效果。

### 2. 独立的轨道旁装饰

不安装在车厢上、单独放置时，它可作为纯装饰方块——车站设备柜、模拟变电所部件、接触网下方的轨道旁地面装备等。右键不会有任何反应。

## 安装

1. 从创造模式物品栏的 TSU 标签页获取，或通过 `/give @s trainsystemutilities:fe_inverter_dummy` 获取。
2. 手持并**右键**点击想要放置的位置。它与真正的 FE 逆变器一样是 3 方块设备。
3. 放置时，点击位置成为**中心**，并沿朝向方向自动放置 3 方块（前方的 HEAD / 后方的 TAIL）。
4. 若前后没有空余空间则无法放置。
5. **空手右键它不会有任何反应**（它是装饰方块，没有状态显示）。

## 安装到列车上时的行为

```
[车厢 1：受电弓 + 模拟逆变器]
       ↓
   管理 UI 中显示电气化信息面板（FE 显示读作"装饰模式"）
       ↓
   可从 UI 进行"全部展开" / "全部折叠"受电弓操作
       ↓
   经过接触网下方 → 受电弓杆在视觉上被接触网压下
       ↓
   不会发生 FE 取流（装饰模式）
```

> [!NOTE]
> **与真 FE 逆变器混用也没问题。**
> 如果在同一列车上安装 1 个真逆变器 + 若干模拟逆变器，整列车仍被视为"电气化列车"，只有真的那个负责取流 / FE 管理。模拟的只是额外添加装饰性槽位。

## 注意事项

- 一列**仅**使用模拟逆变器作为逆变器的列车，即使在接触网下运行也永远不会积累任何 FE。若想以电力运行，请至少安装一个真正的[FE 逆变器](fe-inverter.md)。
- 在管理 UI 中，可通过"电气化详情"对话框中该车行是否显示 **`(Decorative mode)`** 徽标来区分模拟与真品。
