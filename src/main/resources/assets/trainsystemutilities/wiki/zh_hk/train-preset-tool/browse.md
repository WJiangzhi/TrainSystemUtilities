# 預設瀏覽 / 放置

![](bws:trainsystemutilities:wiki/screens/train-preset-browse-mine__ja_jp.png)

**列車預設工具**的主界面，用於瀏覽 / 放置 / 上傳 / 刪除已保存的預設。

[[TOC]]

## 打開 / 持有

此界面需在列車預設工具處於 **GUI 模式**時打開（切換到該工具後即為 GUI 模式）。

1. **手持**列車預設工具。
2. 直接**右鍵**（默認：**鼠標右鍵**）即可打開此界面。
3. 要關閉，請按 **Esc** 或**左鍵**屏幕右上角的 **"×"**。

> [!NOTE]
> 如果右鍵後打開的是別的界面（保存界面）或執行了放置動作，説明工具處於 GUI 以外的模式。
> 請用 **Alt + 鼠標滾輪**回到 **GUI 模式**，再右鍵（當前模式會顯示在快捷欄上方）。

## 模式切換（下拉菜單）

**左鍵屏幕頂部的模式指示器（下拉菜單）**打開列表，再**左鍵"我的 / 放置"**進行切換。

| 模式 | 內容 |
|---|---|
| **我的**（本地） | 本地保存的預設（即你自己保存的） |
| **放置**（公開） | 可從 [Preset Place](../preset-place/overview.md) 下載的在線預設 |

## 主要操作

| 操作 | 行為 |
|---|---|
| **左鍵**某個卡片 | 選中預設 → 在右側面板顯示 3D 預覽 |
| **右鍵**某個卡片 | 刪除確認（"我的"模式） |
| 將卡片**拖放**到右側面板 | 準備放置，出現預覽和所需材料，並附帶"▶ 執行 / ✖ 取消"按鈕 |
| 左鍵 **"▶ 執行"** | 確認放置，此界面關閉，工具切換到**放置模式** |
| 左鍵**刷新按鈕** | 重新加載列表 |
| 左鍵上傳圖標 | 上傳到 Preset Place（[上傳](../preset-place/upload.md)） |

## 3D 預覽

右側面板以 3D 形式展示選中的預設。可在預覽上操作鼠標：
- **左鍵拖動**：旋轉
- **右鍵拖動**：平移
- **鼠標滾輪**：縮放

## 檢索（放置模式）

按名稱檢索公開預設。**左鍵頂部的搜索框**，輸入名稱，並配合下方排序方式縮小範圍：
- 創建日期 / 點贊數 / 下載量

## 材料顯示

列出選中預設所需的方塊 / 物品。
不足的數量以**紅色**顯示，充足的以**綠色**顯示。詳情見[材料補充](refill.md)。

## 材料來源

在右側面板的**材料來源膠囊按鈕**上滾動**鼠標滾輪**，可切換所需材料的抽取來源：

| 來源 | 行為 |
|---|---|
| **箱子** | 從已鏈接的箱子自動抽取 |
| **ME** | 從 AE2 網絡抽取 |

> [!TIP]
> 要鏈接箱子，請在手持工具（GUI 已關閉、處於普通手持狀態）時，對目標箱子使用 **Shift + 中鍵**。

## 膠水箱

放置時所需的 Create 超級膠水（粘合劑）數量在此顯示。

- **左鍵 `Refill` 按鈕** → 打開[材料補充](refill.md)界面，可用粘液球等為膠水箱補充。
- **左鍵 `Dump` 按鈕** → 丟棄膠水箱中的全部內容。

## 放置流程

用"▶ 執行"確認後，GUI 會關閉，工具切換到**放置模式**。隨後在世界中放置：

1. 在你想放置列車的位置**右鍵鐵軌**（默認：**鼠標右鍵**），設定**原點**。
2. **Alt + 滾輪**以 90° 為步長旋轉朝向（按需）。
3. 再次**右鍵**執行放置，此時會消耗材料和粘合劑。
4. 若放置失敗且可重試，可**中鍵**重試，或用 **Shift + 中鍵****取消**放置模式並回到 GUI 模式。
