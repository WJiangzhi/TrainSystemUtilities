# 電子時刻表標籤頁

![](bws:trainsystemutilities:wiki/screens/management-computer__schedule__ja_jp.png)

管理用計算機的"電子時刻表"標籤頁。以電子方式管理列車的 Create 時刻表——你可以編輯它、將其導出為實體物品，並與其他列車共享。

[[TOC]]

## 如何打開

1. **放置**管理用計算機方塊並**右鍵點擊**它以打開界面。
2. **點擊**左上角下拉菜單並選擇**"🕒 電子時刻表"**。
3. 當列車過多無法在列表中全部顯示時，在列表上轉動**鼠標滾輪**滾動。

> [!NOTE]
> 在此標籤頁頂部還有**"⏹ 全部列車停車" / "▶ 全部列車恢復"按鈕**。點擊它們可一次性停止/恢復此網絡上的所有列車（列車會在到達車站時依次停車）。

## 三種時刻表狀態

每個列車磁貼顯示其時刻表的狀態。

| 狀態 | 含義 |
|---|---|
| 電子時刻表 | 在此管理用計算機上設置和管理。可編輯 / 導出 / 共享 |
| 普通時刻表 | 直接交給乘務員的實體時刻表物品。無法從計算機編輯 |
| 無 | 未設置時刻表 |

## 詳情視圖

![](bws:trainsystemutilities:wiki/screens/management-computer__schedule-detail__ja_jp.png)

在列表中**點擊某個列車磁貼**可打開其詳情。

| 元素 | 操作 | 內容 |
|---|---|---|
| 恢復 / 停車 | **點擊**切換 | 一個切換按鈕，停止時顯示"恢復"，運行時顯示"停車" |
| 編輯 | **點擊** | 編輯電子時刻表（滿足條件時啓用；[見下文](#編集の條件)） |
| 🔗 共享 | **點擊** | 將時刻表共享給其他列車（[共享](#share)） |
| ◀ 返回 | **點擊** | 關閉詳情並返回列表 |
| 條目 | 在列表上用**鼠標滾輪**滾動 | 時刻表條目列表 |

### 編輯條件 {#編集の條件}

要啓用編輯按鈕，需要滿足以下所有條件：

- 列車已**停車**
- 是**電子時刻表**（普通時刻表無法編輯）
- 車上有**乘務員**（怪物或烈焰人燃燒器）

> [!TIP]
> 當條件不滿足時，編輯按鈕的文字會變為提示原因。**"無法編輯"** = 普通時刻表，**"需要乘務員"** = 車上無乘務員，**"已共享"** = 因為是其他列車共享的只讀狀態。在這些狀態下，點擊不會打開編輯界面。

### 右鍵點擊乘務員

對於電子時刻表列車，右鍵點擊乘務員可**切換恢復 / 停車**，且**時刻表物品無法取出**（因為它是以電子方式設置的）。普通時刻表仍可像以前一樣通過右鍵點擊取出物品。

## 時刻表編輯器彈窗 {#sched-editor}

![](bws:trainsystemutilities:wiki/screens/management-computer__schedule-editor__ja_jp.png)

在詳情中**點擊"✎ 編輯"按鈕**，會在界面左側打開編輯彈窗（如果左側放不下則顯示在右側）。它以官方 Create 名稱處理所有 Create 時刻表指令和條件。

### 條目操作

- **添加條目**：**點擊彈窗底部的"添加動作"按鈕** → 從出現的列表中**點擊選擇**（🚉 車站 / 📦 卸貨 / 📥 裝貨 / 📝 重命名 / 🔧 限速）。
- **重新排序**：**點擊每個條目上的上箭頭 / 下箭頭**可將其上移 / 下移一格。
- **刪除**：**點擊條目上的 ✕**。
- **切換循環 / 單程**：**點擊編輯器頂部的"↻ 循環" / "→ 單程"開關**（循環模式在到達末尾後回到開頭）。
- **確認 / 取消**：底部**點擊"✓ 應用"保存**，**點擊"× 取消"放棄**。

### 每個條目的等待條件

每個條目可分配一個或多個**等待條件**。

- **添加條件**：**點擊條目上的添加條件按鈕** → 從列表中**點擊選擇**（⏱ 等待 / ⌚ 時間 / 👤 乘客數 / 📦 物品 / 💧 流體 / 🚃 連掛等）。
- **修改條件的數值**：將**光標懸停在數值上**（如等待秒數）**並轉動鼠標滾輪**（向上增大 / 向下減小）。
- **刪除條件**：**點擊條件上的 ✕**。

示例：

| 條件 | 行為 |
|---|---|
| `⏱ Wait` | 等待設定時間 |
| 👤 乘客數 | 等待乘客上車 |
| `📦 Item` / `💧 Fluid` | 等待貨物裝載完成 |
| 🚃 連掛 | 等待連掛（[連掛 / 解編](../trains/coupling.md)） |

### 添加條目（選擇車站）

在"添加動作"下選擇**🚉 車站 / 📦 卸貨 / 📥 裝貨**時，會緊接着打開一個車站選擇列表。**點擊目的車站**即可添加該條目。當車站很多時，在列表上用**鼠標滾輪**滾動。

## 導出為時刻表 {#export}

電子時刻表可寫出到實體的"時刻表"物品。

- **將空的時刻表物品拖入輸入槽** → **箭頭形進度條**推進 → 輸出槽出現寫好的物品，**將其取出**。
- **點擊"全部導出"開關將其打開**可導出與放入輸入槽數量相同的副本（關閉則只導出一個）。

## 與其他列車共享 {#share}

![](bws:trainsystemutilities:wiki/screens/management-computer__schedule-share__ja_jp.png)

電子時刻表可與**同一網絡上的其他列車**共享。

- 在詳情中**點擊"🔗 共享"按鈕** → 打開列車列表 → 在目標列車所在行**點擊開關將其打開**（綠色），將其設為共享目標。當列車很多時，在列表上用**鼠標滾輪**滾動。
- 被共享的列車變為**只讀**，並顯示"正在與（列車名）共享時刻表"。
- 編輯源時刻表會**自動傳播**到被共享列車的時刻表。
