# 車站標籤頁

![](bws:trainsystemutilities:wiki/screens/management-computer__stations__ja_jp.png)

管理用計算機的"車站"標籤頁。所有車站的列表、車站組管理，以及線路編號分配。

[[TOC]]

## 如何打開

1. **放置**管理用計算機方塊並**右鍵點擊**它以打開界面。
2. **點擊**左上角下拉菜單並選擇**"🏯 車站"**。
3. 當車站過多無法在列表中全部顯示時，在列表上轉動**鼠標滾輪**滾動。

## 顯示內容

| 列 | 內容 |
|---|---|
| 車站名 | Create 車站名 |
| 組 | 所屬車站組（用[車站範圍指定工具](../tools/station-range-tool.md)註冊） |
| 線路編號 | 已分配的編號（如 JA01） |
| 列車檢測 | 最近經過的列車 |

## 車站組管理

列出用[車站範圍指定工具](../tools/station-range-tool.md)創建的車站組，你可以：
- 查看成員車站
- 重命名組
- 刪除組

## 車站詳情與控件

- **選擇車站**：在列表中**點擊某一車站的行**可打開其詳情（車站名、位置、所屬組、車門方向等）。
- **返回列表**：在詳情中**點擊"◀ 返回"按鈕**。
- **設置車門開啓側**：在詳情中**點擊**方向按鈕（**北 / 南 / 東 / 西 / 自動 / 無**）來選擇。

## 線路編號分配（分配彈窗）

![](bws:trainsystemutilities:wiki/screens/management-computer-station-assign__ja_jp.png)

- **打開分配彈窗**：在列表中**點擊每個車站行上的分配按鈕（＋）**，會在該車站正下方打開一個線路編號列表。
- **分配編號**：從列表中**點擊你想分配的線路編號**（選擇"無"可清除分配）。
- 你能分配的編號是預先在[線路編號標籤頁](line-symbols.md)中創建的。

## 線路編號

在[線路編號標籤頁](line-symbols.md)中創建的編號會在此分配給車站。
已分配的編號會顯示在[鐵路管理方塊標題](../railway-management.md)和[線路圖](route-map.md)上。
