# 月臺屏門

```embed:item id=trainsystemutilities:platform_screen_door size=48 label=true
```

用於車站月臺的可動月臺屏門。支援 4 個朝向，並**隨列車到站 / 發車自動開關**。一個單元寬 6 格（兩端為柵欄，中間為 4 格可開啟的門）。

[[TOC]]

## 放置 {#place}

1. 在物品欄中手持月臺屏門。
2. 朝月臺邊緣**右鍵**放置。
3. 屏門會**從你的視角向左右延伸**放置。右鍵前先面向你想要的方向。

> [!NOTE]
> 月臺屏門是寬 6 格的單一方塊。**兩側沒有足夠空位（左 3 / 右 2）時無法放置**（物品不會消耗）。請放置在開闊的月臺邊緣，而不是緊貼前後牆的位置。

> [!TIP]
> 按列車車門位置等距排列多個，可獲得逼真效果。請與[月臺柵欄](platform-fence.md)搭配使用。

## 如何開門（重要） {#how-to-open}

**右鍵月臺屏門不會開啟它。** 手動開關功能已移除；屏門**僅在列車到站 / 離站時自動開關**。要使其開啟，必須按以下步驟將其連結到車站（鐵路管理方塊）。

## 連結到車站 {#link}

將月臺屏門連結到列車需要以下 3 步。它使用與柵欄完全相同的「儲存卡分組」機制。

### 步驟 1：用儲存卡將屏門註冊到組 {#group}

1. 手持**儲存卡**。
2. **右鍵**任意一個你想連結的月臺屏門（也可包含相連的柵欄）。
3. **相鄰且相連的屏門 / 柵欄會一起自動註冊**。聊天欄會顯示「已將 ○ 加入月臺門組（共 ○ 個）」。
4. 持卡期間，已註冊成員會在世界中以**綠色輪廓**顯示。請檢查範圍。
5. 如需移除不需要的成員，對其**Shift + 右鍵**。
6. 可在該物品的**提示資訊**中檢視註冊數量。

### 步驟 2：將卡插入鐵路管理方塊 {#insert-card}

1. **右鍵**該車站的[鐵路管理方塊](../railway-management.md)開啟其 GUI。
2. 從功能下拉框開啟**月臺屏門**設定彈窗。
3. 將步驟 1 的儲存卡放入彈窗中的**卡槽**（僅已註冊分組的儲存卡能放入）。

### 步驟 3：設定開關條件 {#conditions}

在月臺屏門設定彈窗中，註冊屏門應在列車停靠的哪個時刻如何動作的**條件**。最多可新增 16 個條件。

| 條件欄位 | 可選值 | 含義 |
|---|---|---|
| 軌道 | 編號 | 目標軌道（MVP 版本中軌道匹配已簡化） |
| 事件 | 到站 (STOP) / 發車 (DEPART) | 觸發條件的時刻 |
| 動作 | 開門 / 關門 / 更改帶色 | 屏門的動作 |

典型示例：

- 註冊兩個條件「到站 → 開門」和「發車 → 關門」 → 列車到站時屏門開啟，離站時關閉。

無需等待列車，即可透過彈窗中的**測試**控制元件驗證所配置的動作。帶色（組內全部柵欄 / 屏門的帶色）也可從同一彈窗中的顏色按鈕更改。

> [!NOTE]
> 條件註冊在「持有該儲存卡的鐵路管理方塊」上。列車檢測由鐵路管理方塊完成，因此**請將卡插入你希望進行檢測的車站的鐵路管理方塊**。
