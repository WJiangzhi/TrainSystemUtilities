# 顯示器

![](bws:trainsystemutilities:wiki/screens/management-computer__map__ja_jp.png)

管理用計算機的"顯示器"標籤頁。在已連接的附近顯示器方塊上顯示自定義佈局。

[[TOC]]

## 如何打開

1. **放置**管理用計算機方塊並**右鍵點擊**它以打開界面。
2. 顯示器功能通過此界面**頂部的顯示器開關**和**底部的按鈕**（🎨 顏色 / ▒ 佈局）操作（見下方[控件](#操作)）。

## 功能

- 自定義佈局編輯（[佈局編輯器](layout-editor.md)）
- 顏色自定義（[顏色設置](color-settings.md) / [顏色拾取器](symbol-editor.md#color-picker)）
- 顯示器連接（[顯示器連接卡](../tools/monitor-link-card.md)）
- 批量應用 / 翻面 / 私有/公開

## 控件 {#操作}

| 元素 | 操作 | 功能 |
|---|---|---|
| 顯示器開關 | **點擊**開啓/關閉（開啓 = 綠色） | 開啓後開始在已連接的顯示器上顯示（[流程](#モニター連攜の流れ)） |
| 🎨 顏色按鈕（底部） | **點擊** | 打開[顏色設置](color-settings.md)彈窗 |
| ▒ 佈局按鈕（底部） | **點擊** | 打開[佈局編輯器](layout-editor.md) |
| 創建線路編號 | 在左上角下拉菜單中選擇 **Ⓜ Line Symbols** 標籤頁 | 在[線路編號編輯器](symbol-editor.md)中創建和編輯編號 |

> [!NOTE]
> 即使顯示器開關處於開啓狀態，如果你沒有先用[顯示器連接卡](../tools/monitor-link-card.md)連接顯示器方塊，也沒有地方可以顯示。請先完成下方的[顯示器連接流程](#モニター連攜の流れ)。

## 顯示器連接流程 {#モニター連攜の流れ}

1. **放置**管理用計算機。
2. 在附近**放置**顯示器方塊。
3. 手持[顯示器連接卡](../tools/monitor-link-card.md)，**右鍵點擊**顯示器方塊 → **右鍵點擊**管理用計算機以完成連接。
4. 打開管理用計算機並**點擊顯示器開關將其打開**（綠色）→ 立即同步到已連接的顯示器。
