# 接触网桁架

```embed:item id=trainsystemutilities:overhead_truss size=48 label=true
```

一种跨越多条轨道的龙门式高架支撑结构。在双轨或更宽的路段上，单个结构即可悬挂多段接触网。

[[TOC]]

## 放置

从物品栏手持接触网桁架，**右键点击你想要放置的位置**。

- 朝向支持 8 个方向（45° 步进），可跟随斜向路段。
- **向侧方延伸（横梁跨度）**：右键点击已放置的桁架，另一段桁架会沿其朝向在横梁尖端处接续。持续右键可延伸至跨越整个轨道组的长度。
- **连接到斜向支柱**：右键点击斜向升起的[接触网支柱](overhead-pole.md)的侧面，桁架会放置在匹配该支柱朝向的斜向单元上。
- 若要批量放置，[接触网支柱自动工具](../tools/overhead-pole-auto-tool.md)非常方便（在其设置中将"放置桁架"设为 ON，即可让桁架与支柱一起自动排开）。

> [!IMPORTANT]
> 不能直接在桁架上架设接触网。右键在桁架的侧面或底面放置[接触网绝缘子](insulator.md)，然后用[连接工具](wire-connector.md)右键该绝缘子才能架设接触网。

## 到架设接触网的流程

1. 放置桁架使其跨越整个轨道组（右键接续横梁直至达到所需宽度）。
2. 右键在每条轨道大致正上方处放置[接触网绝缘子](insulator.md)。
3. 将[连接工具](wire-connector.md)切换到放置模式，按顺序右键**绝缘子 → 绝缘子**以架设接触网。

> [!NOTE]
> 单轨时，[接触网支柱](overhead-pole.md)更为紧凑。
