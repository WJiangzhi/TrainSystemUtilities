# 線路圖

![](bws:trainsystemutilities:wiki/screens/management-computer__map__ja_jp.png)

管理用計算機的"線路圖"標籤頁。將所有車站和軌道顯示為 2D 地圖。

[[TOC]]

## 如何開啟

1. **放置**管理用計算機方塊並**右鍵點選**它以開啟介面。
2. **點選**左上角下拉選單並選擇**"📁 我的線路圖"**（此標籤頁在啟動後預設開啟）。
3. 在使用[儲存卡](../tools/memory-card.md)預先連線軌道網路後，地圖才會顯示。

## 地圖元素

| 元素 | 渲染方式 |
|---|---|
| 車站節點 | 圓圈 + 車站名 |
| 軌道邊 | 連線車站的線 |
| 列車位置 | 實時小圖示 |
| 訊號 | 狀態（紅 / 綠） |

## 控制元件

地圖透過**平移 / 縮放 / 點選圖示**操作。

| 操作 | 方法 | 行為 |
|---|---|---|
| 平移（移動） | 在地圖上**按住滑鼠左鍵並拖動** | 上下左右移動檢視 |
| 縮放 | 在地圖上**轉動滑鼠滾輪** | 向上放大，向下縮小 |
| 選擇列車 | **左鍵點選列車圖示** | 開啟該列車的**詳情彈窗**（疊加在地圖上，可檢視速度、目的地、時刻表等） |
| 選擇車站 | **左鍵點選車站圖示** | 切換到**車站標籤頁**並開啟該車站的詳情（線路編號分配等） |

> [!TIP]
> "點選"是指"原地按下並鬆開，不拖動"。即使稍微移動也會被視為平移。請瞄準圖示旁邊快速按下並鬆開。

## 線路編號渲染

車站節點會顯示其[線路編號](line-symbols.md)（已分配時）。
在[車站標籤頁](stations.md)中重新分配會立即反映到地圖上。
