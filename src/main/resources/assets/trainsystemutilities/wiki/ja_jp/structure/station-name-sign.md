# 駅名サイン (Station Name Sign)

```embed:items size=48 cols=2 label=true ids=trainsystemutilities:station_name_sign,trainsystemutilities:station_name_sign_pole
```

駅のホームに掲げる駅名標です。横 4 ブロック × 高さ 1 ブロックの看板で、**駅グループの範囲内に置くと駅名・路線色・隣の駅を自動で表示**します。表と裏の両面に同じ内容が出ます。設定 UI はありません — 表示内容はすべて駅グループと路線記号から自動で決まります。

[[TOC]]

## 設置 {#place}

1. 駅名サインを手に持ち、設置したい場所を **右クリック** します。表示面が自分の方を向くように置かれます。
2. 横 4 ブロックぶんの空間が必要です。足りない場合は設置がキャンセルされ、アイテムは消費されません。
3. どれか 1 セルを壊すと 4 セルまとめて撤去され、アイテムがドロップします。

> [!WARNING]
> **駅グループの範囲外に置いたサインには何も表示されません** (白いパネルのまま)。必ず [駅範囲指定ツール](../tools/station-range-tool.md) で作った駅グループの範囲内に設置してください。

## ポール付きの設置 (吊り下げ) {#pole}

ポール付きは看板の両端に高さ 1 ブロックの吊りポールが付いた、全高 2 ブロックのバリエーションです。

- **天井の下面を右クリック**すると、ポールの上端が天井に接する形で吊り下げ設置されます (看板本体はその 1 ブロック下)。
- ポールが伸びる空間 (両端セルの上) が塞がっていると設置できません。
- 表示の仕様は通常版と同じです。

## 表示される内容 {#display}

| 要素 | 内容 | 出る条件 |
|---|---|---|
| 中央の駅名 | サインが入っている駅グループの名前 | 駅グループ範囲内にあること |
| 路線記号バッジ | 駅名の左に表示 | その駅の Create 駅ブロックに [路線記号](../management-computer/line-symbols.md) が割り当てられていること |
| 帯 (路線色) | 駅名の下の帯。色は **路線記号の縁色** | 同上 |
| 隣の駅 | 帯の左右に白文字で表示 | 線路がつながった先に別の駅グループがあること |

- 駅名の変更や記号の割り当ては、数秒以内にサインへ自動反映されます。
- 隣の駅は **線路のつながり** から求めます: サインの駅から線路をたどり、各方向で最初に見つかった別の駅グループが隣として表示されます。左右の割り当てはサインの向きから自動で決まります。
- 線路や駅グループを変更した直後は、隣の駅の表示が更新されるまで最大 30 秒ほどかかることがあります。

## よくある質問 {#faq}

- **何も表示されない** → 駅グループ範囲外です。範囲を確認してください。
- **帯と記号が出ない** → その駅の Create 駅ブロックに路線記号が割り当てられていません。[管理用コンピューターの路線記号タブ](../management-computer/line-symbols.md) で割り当ててください。
- **隣の駅が出ない** → 隣の駅グループまで線路がつながっているか、隣の駅にも駅グループが作られているかを確認してください。
