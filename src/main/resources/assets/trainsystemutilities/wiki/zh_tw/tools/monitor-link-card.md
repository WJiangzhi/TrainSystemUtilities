# 顯示器連線卡

```embed:item id=trainsystemutilities:monitor_link_card size=48 label=true
```

一種**專用的手持物品**，用於將顯示器方塊連結到另一個方塊（鐵路管理方塊 / 海報管理方塊 / 管理用計算機）。

[[TOC]]

## 持有 / 使用

此卡沒有專用 GUI，只需**手持它並右鍵顯示器**即可使用。

1. **將顯示器連線卡放入快捷欄並手持。**
2. **右鍵要連結的顯示器方塊**（預設為**滑鼠右鍵**）。
   - 相鄰且相連的顯示器會**自動一起註冊為一組**（無需逐麵點選）。
   - 對已註冊的組再次右鍵則會**取消註冊**該組。
3. 註冊成功後，螢幕底部（快捷欄上方）會顯示"已註冊（○組）"。
4. 手持該卡時，將游標懸停可在**提示資訊**中檢視已註冊內容："已註冊：○"。
5. **Shift + 右鍵**（潛行時右鍵）即可**清除**該卡的全部已註冊內容。

> [!NOTE]
> 此卡記錄的是"已註冊的顯示器"。要真正將顯示內容輸出到顯示器，
> 請將這張已註冊的卡**放入鐵路管理方塊等方塊的顯示器插槽**中（參見下文"使用流程"）。

## 操作一覽

| 操作 | 效果 |
|---|---|
| **右鍵**顯示器 | 註冊該顯示器（相連的一組）/ 若已註冊則取消註冊 |
| **Shift + 右鍵** | 清除該卡的全部已註冊內容 |
| 游標**懸停**於卡上 | 在提示資訊中檢視當前註冊數量 |

## 使用流程

1. 按上述步驟在卡上**註冊**顯示器。
2. 將已註冊的卡放入你希望作為來源的方塊的**顯示器插槽**中（[鐵路管理方塊](../railway-management.md) / [海報管理方塊](../poster-management.md) / [管理用計算機](../management-computer/monitor.md)）。
3. 該方塊的顯示內容會立即同步並顯示在已註冊的顯示器上。

## 可連結的組合

| 來源 | 顯示內容 |
|---|---|
| [鐵路管理方塊](../railway-management.md) | 車站到站 / 下一班列車 + 線路符號 |
| [海報管理方塊](../poster-management.md) | 輪播圖片 |
| [管理用計算機顯示器](../management-computer/monitor.md) | 自定義佈局 |

## 顯示器方塊放置

顯示器可以是單個方塊，也可以是**多面顯示器**（即 行 × 列 的網格）。
用卡連結後，內容會拉伸鋪滿整個網格。
