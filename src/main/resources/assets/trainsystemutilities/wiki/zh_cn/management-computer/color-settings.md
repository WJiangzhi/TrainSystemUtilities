# 颜色设置

```embed:color-settings
```

管理用计算机的颜色设置弹窗。自定义显示器上每个元素的颜色。

[[TOC]]

## 如何打开

1. **放置**管理用计算机方块并**右键点击**它以打开界面。
2. **点击界面底部的"🎨 颜色"按钮**打开显示器颜色设置弹窗。

## 可重新着色的元素（目标）

**点击弹窗顶部的"目标："下拉菜单**，然后**点击**你想重新着色的元素。可用元素：

| 目标 | 描述 |
|---|---|
| 标题 | 面板标题文字颜色 |
| 边框 | 面板边框颜色 |
| 列车名 | 列车名文字颜色 |
| 速度 / 状态 | 速度和运行状态文字颜色 |
| 目的地 | 目的地文字颜色 |
| 时钟 | 时钟显示颜色 |
| 统计数值 | 车站数和列车数等数字的颜色 |
| 信号（绿） | 地图上绿色信号的颜色 |
| 信号（红） | 地图上红色信号的颜色 |
| 地图线条 | 地图上线条的颜色 |
| 地图车站 | 地图上车站图标的颜色 |
| 地图列车 | 地图上列车图标的颜色 |

## 用法

1. **选择目标**：点击"目标："下拉菜单 → 从上方列表中点击一个元素。
2. **选择颜色**：直接**点击下方某个预设颜色**即可应用到所选目标。"当前："显示当前颜色。
3. **还原**：**点击"重置"按钮**可将所选目标恢复为默认颜色。**点击"全部重置"按钮**可将所有目标恢复为默认颜色。
4. **关闭**：**点击弹窗右上角的 ✕（关闭）按钮**。

## 预设

12 种预设颜色可通过**点击**一键应用。

## 范围

颜色设置以管理用计算机为单位。
相同的颜色会应用到每个已连接的显示器。
