# 存儲卡

```embed:item id=trainsystemutilities:memory_card size=48 label=true
```

存儲卡是一種通用鏈接卡，用於將鐵路網絡和車站方塊鏈接到**管理用計算機**，或將**月台屏門 / 月台柵欄**註冊為一組。使用分為兩步：先"保存"一個位置，再將其"應用"到另一個方塊。

[[TOC]]

## 基本用法

1. **保存**：**右鍵**鏈接源（鐵軌 / 鐵路管理方塊 / 月台屏門等），將其位置記錄到卡上。
2. **應用**：**右鍵**鏈接目標（通常是管理用計算機），將記錄的內容應用上去。
3. 可在物品的**提示信息**中查看卡當前保存的內容。
4. **Shift + 右鍵**（在空處或非目標方塊上）即可**重置卡片**。

## 存儲卡可操作的對象

| 目標 | 右鍵 | Shift + 右鍵 |
|---|---|---|
| Create **鐵軌** | 保存鐵路網絡（記錄車站 / 信號 / 列車數量） | （重置） |
| **鐵路管理方塊** | 保存該車站方塊（含車站名稱） | （重置） |
| **管理用計算機** | **鏈接**已保存的鐵路網絡 / 鐵路管理方塊 | （重置） |
| **月台柵欄 / 月台屏門** | **將相連的圍欄 / 屏蔽門一起註冊為一組** | **將該成員從組中移除** |

> [!NOTE]
> **鏈接到顯示器需使用專用的[顯示器連接卡](monitor-link-card.md)**（與存儲卡是不同的物品）。列車檢測請使用[列車檢測卡](train-detection-card.md)。

## 常用操作

**將鐵路網絡鏈接到管理用計算機**

1. **右鍵線路上的任意鐵軌** → 顯示"鐵路網絡已保存"。
2. **右鍵管理用計算機** → 顯示"鐵路網絡已鏈接"。
3. 該鐵路網絡隨即出現在管理用計算機的路線圖 / 列車列表中。

**將車站的鐵路管理方塊綁定到計算機**

1. **右鍵車站站台上的鐵路管理方塊**，將其保存。
2. **右鍵管理用計算機**，完成鏈接。

**將月台屏門 / 月台柵欄編組**

1. **右鍵**其中一扇門 / 一段圍欄，相鄰相連的方塊會自動一起註冊。
2. 用 **Shift + 右鍵**排除多餘的成員。
3. 關於該組與車站的關聯，請參見[月台屏門](../structure/platform-screen-door.md)。

## 與訪問模式無關

使用存儲卡進行鏈接 / 讀取時，不受訪問模式（私有 / 公開）影響。
