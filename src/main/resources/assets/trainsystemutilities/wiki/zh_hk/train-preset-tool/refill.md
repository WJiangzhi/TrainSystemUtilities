# 材料補充

![](bws:trainsystemutilities:wiki/screens/train-preset-refill__ja_jp.png)

用於補充列車預設工具的粘合劑（Create 超級膠水）膠水箱的 **GUI**。放置預設時，會消耗粘合劑將列車方塊粘合在一起，可在此補充。

[[TOC]]

## 打開

此界面從[預設瀏覽 / 放置界面](browse.md)打開。

1. 手持列車預設工具並**右鍵**，打開[預設瀏覽 / 放置界面](browse.md)（GUI 模式下）。
2. 在右側面板的膠水箱區域**左鍵 `Refill` 按鈕**。
3. 即打開此補充界面。要關閉，請按 **Esc** 或**左鍵**右上角的 **"×"**。

## 可執行的操作

| 功能 | 概要 |
|---|---|
| 補充膠水箱 | 放入粘液球 / 粘液塊為膠水箱補充 |
| 液位顯示 | 以量表顯示當前 / 最大量（如 `0 / 10000`） |
| 排空 | 丟棄膠水箱的全部內容 |

## 補充粘合劑的方法

將**粘液球**或**粘液塊**放入屏幕中央的**輸入槽**（不接受其他物品）。

1. **左鍵**將物品欄中的粘液球 / 粘液塊移入輸入槽（**Shift + 左鍵**可批量移入）。
2. 一旦放入，便會自動添加到膠水箱（膠水箱容量換算：1 個粘液球 = 10，1 個粘液塊 = 90。最大容量為 10000）。
3. 當膠水箱快滿、連一個都放不下時，不會添加任何內容，物品會留在槽中。
4. 關閉界面時，輸入槽中剩餘的物品會自動退還到你的物品欄。

> [!NOTE]
> 在此界面放入的**僅限粘合劑（粘液）**。構成列車本身的方塊（鐵軌、玻璃板等）
> 並不在此抽取，而是在放置時從[預設瀏覽 / 放置界面](browse.md)中指定的**材料來源（箱子 / ME）**抽取。

## 液位與排空

- 屏幕頂部顯示**當前 / 最大量**及量表。
- **左鍵 `Dump` 按鈕**會丟棄膠水箱的全部內容。

## 與預設放置的聯動

在[預設瀏覽 / 放置界面](browse.md)中，將 3D 預覽拖入右側面板 → 用"▶ 執行"確認放置 → 在世界中放置時，會消耗此處儲存的粘合劑。
若粘合劑不足，放置時會以紅色顯示警告，無法放置。
