# 个人资料

![](bws:trainsystemutilities:wiki/screens/preset-place-profile__ja_jp.png)

按用户区分的页面。有两种模式：自己的主页和他人的主页。

[[TOC]]

## 打开 {#open}

- **你自己的主页** … 在 **GUI 模式**下**右键**[列车预设工具](../train-preset-tool/browse.md) → 将模式设为 **`Place`（公开）**，并**左键**顶部的你的名字 / 图标区域。
- **他人的主页** … 在[预设详情](detail.md)页面，**左键上传者的名字**即可打开。

首次打开时，可能会要求你进行 Microsoft 账号认证。请按界面提示操作。

## 模式 {#modes}

视页面是自己还是他人，可执行的操作有所不同。

| 模式 | 内容 |
|---|---|
| **自己的** | 编辑主页 / 更换图标 / 查看数据 / 前往创作者中心 |
| **他人的** | 浏览公开预设 / 关注 |

## 按钮操作 {#buttons}

| 按钮 | 显示条件 | 操作 / 行为 |
|---|---|---|
| 关注 | 他人主页 | **左键**关注 / 取消关注（已关注时为灰色，未关注时为橙色） |
| 创作者中心 | 自己的主页 | **左键**打开[创作者中心](creator-center.md) |
| 编辑图标 | 仅自己的主页和官方账号 | **左键**打开图标编辑器 |
| 预设卡片 | 两者 | **左键**前往该预设的[详情](detail.md) |
| × / 返回 | 两者 | 关闭 / 返回 |

## 主页图标 {#icon}

支持 SVG 格式的自定义图标。
编辑在主页图标编辑器中完成（一个专用弹窗，从你自己主页上的 **"编辑图标"按钮**打开）：

- 加载 SVG 文件
- 调整缩放 / 偏移
- 设置背景色 / 边框色
- **仅官方账号可编辑**（普通用户不会显示编辑按钮）

## 数据显示

你自己的主页会显示：
- 公开预设数
- 累计下载量
- 累计点赞数
- 关注者数
