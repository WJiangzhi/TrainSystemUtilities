# 佈局編輯器

```embed:layout-editor
```

管理用計算機的佈局編輯器。編輯顯示器上各面板（線路圖、列車列表、時鐘等）的放置位置和大小。

[[TOC]]

## 如何打開

1. **放置**管理用計算機方塊並**右鍵點擊**它以打開界面。
2. **點擊界面底部的"▒ 佈局"按鈕**打開佈局編輯器。
3. 編輯器中央有一個代表實際顯示器的**預覽框**，左側（或頂部）有一列可放置面板的**面板庫**。

## 可放置面板（面板庫）

面板庫包含以下磁貼。**將它們拖到預覽框上**即可放置。

| 磁貼 | 內容 |
|---|---|
| 🗺 線路圖 | 線路網絡地圖 |
| 🚂 列車 | 列車列表 |
| 🕒 時刻表 | 時刻表 |
| 🏯 車站數 | 車站總數 |
| 🚆 列車數 | 列車總數 |
| 🚦 信號數 | 信號總數 |
| 🕓 時鐘 | 時間顯示 |

## 控件

在預覽框內按以下方式放置、移動和調整面板大小。

| 操作 | 方法 | 結果 |
|---|---|---|
| 添加面板 | **按住面板庫磁貼，拖到預覽框上並鬆開** | 在該位置添加一個面板 |
| 移動面板 | 在預覽內**左鍵拖動**面板 | 移動其位置（自動調整以保持在框內） |
| 調整面板大小 | **將光標懸停在面板上並滾動鼠標滾輪**（上 = 放大 / 下 = 縮小） | 以中心為基準縮放面板 |
| 選擇面板 | **點擊**面板 | 使其進入選中狀態 |
| 刪除面板 | 選中後按 **Delete 鍵** | 刪除所選面板 |
| 單面板設置 | **用鼠標中鍵（按下滾輪）點擊面板** | 打開該面板的功能專用設置彈窗（[見下文](#機能別設定-popup)） |

## 功能專用設置彈窗 {#機能別設定-popup}

**中鍵點擊**面板會打開一個彈窗，可在其中單獨調整該面板內文字和圖標的大小。

| 項目 | 內容 |
|---|---|
| 文字大小 | 面板內基礎文字大小 |
| 文字 / 線條大小 | 地圖上文字和線條的粗細 |
| 列車圖標 | 地圖上列車圖標的大小 |
| 車站圖標 | 地圖上車站圖標的大小 |
| 信號圖標 | 地圖上信號圖標的大小 |

- **修改數值**：將**光標懸停在數字上並滾動鼠標滾輪**（向上增大 / 向下減小）。**將其設為 0 即為"自動（推薦）"**，會根據顯示器和麪板大小計算最優值。
- **將全部重置為自動**：**點擊"✨ 推薦（自動）"按鈕**。
- **關閉**：**點擊"關閉"按鈕**。

## 編輯器底部的按鈕

| 按鈕 | 操作 | 結果 |
|---|---|---|
| 🗑 全部清除 | 點擊 | 移除所有已放置的面板 |
| ✨ 推薦 | 點擊 | 自動排列推薦佈局 |
| ✓ 保存 | 點擊 | 保存當前佈局並關閉 |

## 保存佈局

"✓ 保存"會將佈局存儲到管理用計算機內部。
通過[顯示器連接卡](../tools/monitor-link-card.md)連接的每個顯示器都會應用相同的佈局。
